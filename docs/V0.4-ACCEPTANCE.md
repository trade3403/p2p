# V0.4 Acceptance — Remote Operations

- [x] Windows Rust/Iced: selectable monitor and matching screenshot/input coordinates
- [x] Windows separate clipboard consent toggle, default off

- [x] Android monitor selection, right click, wheel up/down

## Deliberately not claimed

- Full file transfer, H.264 hardware video, audio, multi-user access, locked/UAC desktop, signed release, or production security audit.
- No VPS deployment was performed by CI; requires your domain and server access.

All remote input and clipboard operations require an explicit, visible Windows application permission. Never bypass OS authentication or silently harvest remote clipboard.
