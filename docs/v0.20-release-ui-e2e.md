# V0.20 正式客户端公网 UI 验收

与既有 native public E2E 独立。新任务直接安装同一次 CI 构建出的 NSIS 正式 Windows 安装包和 release Flutter APK。通过系统辅助功能与真实触摸/鼠标驱动界面；不调用 C ABI、不启用调试 RPC，不使用纯色测试窗口。两个官方 Runner 通过 p2ptest.aikissgo.com 独立加密协调房间交换临时设备号、验证码和测试窗口坐标。Token 只由 GitHub Secret 注入，配置阶段不录像，验证码默认遮挡。录屏为实际 OS 屏幕，不是接收帧拼接。

验收必须同时通过：正式安装、UI 配置、真实数字配对及人工授权按钮、全屏视频、Windows Notepad 实际点击、窗口位置变化、Android UI 输入的唯一文本由 Windows 剪贴板读回、UI 断开、两端 MP4 解码校验。若任一失败，任务失败并保留已产生的证据。录屏 4fps 为采样频率，不代表远控实际帧率。全屏为独立远控页面，保留退出和断开操作。H.264 实时性能与真实手机验收仍是单独目标，不将录屏编码 H.264 等同于远控 H.264。

正式包 UI 验收不读取原生状态或直接调用控制接口；若 OS 辅助功能定位或窗口交互不可靠，需修复自动化，不得用协议测试替代。现有测试及发布产物不删除，main/V0.19 不改。仅使用临时 GitHub Windows 桌面、空记事本文档和 Android 模拟器。
