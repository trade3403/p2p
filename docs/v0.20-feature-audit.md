## 公网 E2E（独立工作流）

- Windows 官方 Runner：编译真实 Rust DLL；通过 C ABI 启动 Host；仅在专用临时桌面显示可辨认的测试图案，真实截图由原生引擎采集。
- Ubuntu 官方 Runner：API 35 Android 模拟器；仪器测试调用同一个 AndroidRemoteEngine，走 HTTPS 配对、真实 WSS、AES-GCM 解密及 Bitmap 解码。
- 中转固定为 p2ptest.aikissgo.com；从 Actions Secret RELAY_ACCESS_TOKEN 获取访问凭据。缺失或服务器错误必须失败。
- 双 Runner 用独立临时加密 WSS 协调房间交换本次设备号和验证码；不将凭据输出至日志、命令行或 artifacts。
- 每次只注册一个新的 CI 测试设备。服务器当前没有设备注销 API，注册记录可能持久保留；配对窗口会过期。禁止对真实用户设备发起操作。
- 真实验证：配置、配对、加密 JPEG、默认权限拒绝、授权后点击/Enter、剪贴板、接收 FPS、认证 RTT、取消真实 WebSocket 后自动恢复、手动停止。
- MP4 来自 Android 引擎实际收到并解码、验证测试标记的 JPEG 帧，不是 Flutter 发布版 UI 录屏；采样视频固定 5fps 播放，性能以 JSON 实测值为准。
- CI 成功只代表相应自动化断言通过；当前 E2E 不覆盖 Flutter 发布版 UI 的真实配对按钮操作、Android 真机、Windows Viewer 重连、H264、LAN/ICE、托盘及所有输入种类。以上必须分别验收，不能用模拟或截图替代。
- V0.20 独立 build workflow 保留 Rust/Kotlin/Flutter/Go 单测、安装包和离线 UI 测试。公网 E2E 不改 Linux 服务及 main/V0.19 分支。
