# V0.5 Acceptance and Security Boundaries

## Delivered in source (confirm CI first)

- [x] Windows DPAPI CurrentUser encrypted trusted profile (relay token, session key, server URL, two opt-ins).
- [x] Explicit per-user login-start option via HKCU Run; no elevated service, no hidden process.
- [x] Separate consent for restoring remote mouse/keyboard authorization after login-start (default OFF).
- [x] Explicit Windows revoke: stop session, clear permissions, delete saved credentials and auto-start, rotate session key.
- [x] Closing the Windows application stops active session via Drop.
- [x] Android Keystore AES-GCM encrypted profile in private preferences; one saved home computer.
- [x] Android explicit connect-saved, save, and remove-local buttons; no automatic app startup.
- [x] DPAPI roundtrip test on Windows; profile validation test.
- [x] V0.5 Actions workflow for Windows EXE, Android APK and Go relay.

## Required CI gates

- [ ] Windows cargo test (including DPAPI) succeeds.
- [ ] Windows cargo build --release succeeds; EXE zipped with SHA-256.
- [ ] Android testDebugUnitTest and assembleDebug succeed; APK with SHA-256.
- [ ] Go relay go test -race and Docker smoke build succeed.
- [ ] Build artifacts contain only test binaries and no credentials.
- [ ] Only merge to main after verifying all jobs.

## Manual VPS and real-device acceptance (unavailable without owner's access)

- [ ] On authorized VPS, deploy Caddy HTTPS and relay Docker image; healthz is HTTP 200.
- [ ] Windows 10/11 current user chooses auto-start, logs out/in and sees app visibly running.
- [ ] With persistent-input authorization OFF, Android cannot send accepted mouse/keyboard input until manually enabled on Windows.
- [ ] With ON, user-authored opt-in is persisted and remote input works only for the paired session.
- [ ] Android user explicitly saves and reopens the app: one-tap connect works.
- [ ] No token or session key is stored in plaintext; Keystore and DPAPI blobs are unreadable without their local keys.
- [ ] Windows revoke stops the active session and rotates key; old Android profile cannot reconnect.
- [ ] Closing Windows window stops screen/control network traffic.
- [ ] Transient network outage reconnects while authorized and active; stop cancels retry.
- [ ] Windows locked/UAC/screensaver scenarios are displayed as unsupported or controlled safely.
- [ ] 8-hour stability run on home network plus 5G, with CPU, RAM and bandwidth measurements.
- [ ] Check unsigned APK/EXE security prompts before signing for future releases.

## Not supported (do not claim it works)

- Windows service that starts before user login or captures secure desktop/UAC.
- Invisible background host or silent install, full system tray support, remote login at lock screen.
- Multiple independently identified public-key devices and per-device revoke.
- Full account login/registration, VPS fleet management, server online directory.
- H.264/MediaCodec, audio or file transfer.

All features are intended only for computers and mobile devices the user owns or is authorized to administer.
